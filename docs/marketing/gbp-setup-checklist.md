# Google Business Profile setup checklist

Goal: a complete, photo-rich, review-collecting GBP so Groundwork shows up for
"fence repair / hardscaping / lawn care near me" in Longmont & Boulder County.
Work through top to bottom; items marked star are the ones that move rankings.

## 1. Claim & basics (day 1)

- [ ] Search "Groundwork Landscaping Longmont" on Google Maps — if a profile exists,
  claim it (`google.com/business`). If none exists, create one; use the same name,
  address, and phone everywhere (site footer, invoices, door hangers).
- [ ] Choose primary category **Landscaper**; add secondary categories
  **Fence contractor**, **Hardscaping/Paver installation**, **Lawn care service**.
- [ ] Service-area business: set Longmont + a realistic radius (Longmont, Boulder,
  Lafayette, Niwot, Louisville, Erie). Show street address only if the home office
  is one you're comfortable publishing.
- [ ] Add the phone number that actually rings ((720) 707-5411), hours (incl.
  seasonal notes), website `https://groundworkllc.netlify.app/`, and the exact
  business name format used on the truck.
- [ ] Verify ownership (postcard, video, or phone — whichever Google offers).
- [ ] Set up GBP notifications ON so new reviews/messages get answered same day.

## 2. Profile content (day 1–2)

- [ ] Upload 15–20 photos: hero-before/after case shots, process shots, truck/trailer
  with logo, stone/fence/gate details, crew photo. Logo first, cover = best before/after.
- [ ] Add 4 service sections under Landscaper — Hardscaping, Fencing, Lawn care,
  Xeriscaping — each with 2–3 sentence description, no keyword stuffing.
- [ ] Write the business description (750 chars): who you serve (Longmont & Boulder
  County homeowners), what you build, the one-crew accountability point from the site.
- [ ] Link GBP services to the matching site pages (service pages + work.html).
- [ ] Turn on messaging with a canned reply: "Thanks for reaching out! We're usually
  on job sites — call/text (720) 707-5411 or request a quote at [contact page URL]."

## 3. Ranking movers (week 1)

- [ ] STAR: Get your first 5 reviews. Text past clients a short personal message +
  the review short-link ("Would mean a lot — here's the 1-min link"). Ask after a
  good final walk-through, not months later.
- [ ] STAR: Reply to every review within 48h, first name in the reply, mention the
  neighborhood ("Thanks Dana — glad the Lafayette fence is holding its line!").
  Reply to old/negative ones too; response text affects conversion more than rating.
- [ ] STAR: Add 4+ photos/week going forward. Rotate from the existing case-study
  galleries and the README photo checklist; geotag not reliably used, freshness is.
- [ ] One GBP "What's New" post per week mirroring the social series
  (see social-post-series.md Week 1 and Week 4 — the rebate post doubles as a GBP post).
- [ ] List the before/after instructional Q&A yourself (owner-answered): do you
  charge for estimates? (no — free on-site); do you pull permits? do you do repairs
  or only installs? neighborhoods served?

## 4. Local Services Ads (week 2, after profile is solid)

- [ ] Apply at `ads.google.com/local-services-ads` (Landscaping category, Colorado).
  Requires license/insurance verification + background check.
- [ ] Start with a restrained weekly budget (~min $100–150/week) and judge the
  cost-per-job after ~30 leads, not the first week.
- [ ] For each lead: call same hour, log source, dispute stale/wrong-service leads.
- [ ] LSA and GBP reviews are shared signals — keep stacking reviews either way.

## 5. Measure & repeat

- [ ] Add a "How did you hear about us?" field on the contact form and log it.
- [ ] Once a month: check GBP insights (views, calls, direction requests) and the
  photo/review count; bump whichever is behind the checklist pace.

*Everything marked star is the difference between "profile exists" and "profile
ranks" — budget most of your GBP time there, not on the settings pages.*
