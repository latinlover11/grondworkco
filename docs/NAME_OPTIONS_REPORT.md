## 2. Method

Every cleared name went through the same four legs, all re-run on 2026-11-21
rather than trusted from an earlier pass:

1. **Domain** — Verisign RDAP for `.com` (`404` = unregistered; `200` = taken).
   Control request to `google.com` in the same run so a blocked endpoint cannot
   masquerade as a free name.
2. **Colorado register** — the state's open-data mirror of CDOS entities
   (`data.colorado.gov/resource/4ykn-tg5h.json`), searched on the word and read for
   anything in the trade.
3. **USPTO** — headless Firefox against `tmsearch.uspto.gov`, full result set at
   100 per page, every record parsed for class and status. Class **037**
   (construction/installation) and class **044** (agriculture/horticulture) are the
   two this business would file under.
4. **Usage** — plain web search for the word plus "landscaping", and Facebook/
   Instagram surfaces. This leg is not optional: it is what caught both real
   disqualifiers in this dossier, and neither register ever would have.

Rule applied throughout, taken from the House's own Blue Grama decision: **a live
business using the same words in the same trade is a rejection, however far away
it is.** Proximity makes it worse; it is not required.

## 3. The names that survive

### Waxwing — recommended

| Leg | Result |
|---|---|
| Domain | `waxwinglandscape.com` **free**, `waxwinglandscaping.com` **free**; bare `waxwing.com` taken |
| Colorado register | 10 entities, **none in the trade** — Partners (Boulder), Studios (Lyons), Solar, Holdings, Digital, Analytics, Labs, Place Rental, 1386 Waxwing |
| USPTO | 18 records, 7 live, **none in IC 037/044**, none whose goods mention landscaping, lawn, garden or hardscape |
| Usage | Two adjacent users, both distant, both compound names: *Waxwing EcoWorks Co.* (Lancaster PA, native-plant ecological gardening) and *Waxwing Tree Specialists* (Washington, arborist). Neither claims the bare word in landscaping, neither domain conflicts |

**Why it wins:** a bird is not a material and not a plant genus, so it carries no
descriptive weakness — the failure mode that has dogged every plant-name candidate
here. Cedar and Bohemian waxwings are Front Range birds, so the name has a local
reason to exist without naming a product, a place or a service.

**Its one soft spot:** the bird is not distinctive to Colorado, so the name could
belong to a landscaper anywhere. That is a trademark-strength issue, not a
conflict issue.

### Rabbitbrush — cleanest paperwork, weakest mark

| Leg | Result |
|---|---|
| Domain | `rabbitbrushlandscape.com` **free**, `rabbitbrushlandscaping.com` **free**; bare `rabbitbrush.com` taken |
| Colorado register | 16 entities, one trade-adjacent: *Rabbitbrush Garden Design LLC* (Evergreen), **delinquent since Nov 2010** |
| USPTO | **0 records** (confirmed via the no-results state, not an unrendered page) |
| Usage | No landscaping business trades under the word; it appears only as a native-shrub topic in landscape writing (C&H Landscaping, Arbor Valley Nursery, xeriscape guides) |

**Why it is second:** nothing is in the way, and it is the most Coloradan name in
the field — rabbitbrush grows on the plains around Longmont. But a plant name is
descriptive for a plant trade: it is the Blue Grama problem, and it would be hard
to protect and hard to own in search.

### Kinglet — cleanest register in the field

Added by the 32-word sweep in `BRAND_AND_LAUNCH.md` §2d, and the only name that
beats Waxwing on paperwork.

| Leg | Result |
|---|---|

**Why it is second rather than first:** the word is less familiar, it is easy to

name to say once and have repeated, which matters more to a local trade than an empty
register. On every measurable leg, though, Kinglet is the cleaner name.

## 4. The current name

**Cottonwood & Stone** is not dead. It is weaker than the 2026-11-13 memo said,
for three reasons found on 2026-11-21:

1. **A near-twin in the same county.** *Stone and Cottonwood*, a metal/resin art
   studio in Lafayette (~15 miles), has held `stoneandcottonwood.com` since
   2009-07-24. Different trade, no registered mark, but live commercial use of the
   identical word pair in Boulder County.
2. **"Cottonwood" is already a stone.** T&B Stone, Kő, Earthworks, Edward's Stone,
   Tribble, Rocky Mountain Stone and Eldorado all sell a "Cottonwood" limestone
   line. To designers and stone yards the pairing reads as a *material*.
3. **It is a weak mark regardless.** "Cottonwood" appears in 700+ Colorado entity
   names.

What is still true: the domain is free, no Colorado entity contains both words, no
USPTO mark contains "stone", and there is no live class-37 or class-44 mark in the
family. Nothing legally blocks it. The objection is commercial, not legal.

## 6. What I would do next — 3 suggestions

1. **Secure a Waxwing domain** — re-check both free `.com`s at the moment of
   buying, then register one. Cheap, reversible, and it stops the name being taken
   while the decision is made.
2. **Deepen the Waxwing search** — phonetic equivalents and similar marks
   (Waxwing/Waxwing's/Wax Wing), the Colorado state trademark register, and a
   Boulder County common-law sweep. That is the gap between this dossier and a
   real clearance opinion.
3. **Draft the Waxwing copy** — hero, tagline, about paragraph and page titles —
   so a decision to switch costs one afternoon rather than a rewrite.

## 7. What only the owner can do — 4 items

1. Decide between keeping **Cottonwood & Stone**, switching to **Waxwing**, or
   switching to **Rabbitbrush**.
2. Buy the domain for whichever name wins.
3. Colorado SOS name search at filing, then the LLC.
4. USPTO search on the final goods-and-services wording before any application.
