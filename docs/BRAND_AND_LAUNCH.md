primary source; the methods are listed so any claim can be re-run rather than
trusted.

## 2a. Alternative shortlist, cleared 2026-11-21

Written after the 11-21 re-run (§3) found that "Cottonwood" is a stone product
name and that a Lafayette studio is called *Stone and Cottonwood*. Rules this
shortlist had to pass:

1. **No word that is a material or product name** in the stone or landscape-supply
trade — that reading is what damaged Cottonwood & Stone.
2. **No live business using the word in this trade**, checked by web search and by
the Colorado register.
3. **`.com` obtainable** in a natural "word + landscape/landscaping" form.
4. Sayable out loud, spellable over the phone.

The `"[word] & Stone"` construction was dropped outright: it is what produced the
material reading, and *Sage & Stone Landscape* (Broomfield) already occupies that
pattern in the county.

### The Google listing

No business named Waxwing is listed on Google Maps around Longmont — a maps search
for "Waxwing" centred on the city returns Wing Shack and The Wax Factory and
nothing else. There is no listing to collide with and no incumbent to out-rank
locally.

Google does not reserve or register Business Profile names, so there is no
availability lookup to run. What the guidelines require (read for this, not
recalled): the name must match the business's real-world name as used on signage,
website and invoices; no taglines, service lists, locations or hours in it; no
`LLC`/`Inc` without real-world proof; and one profile per business. Pick **Waxwing
Landscaping** or **Waxwing Landscape** once and use that exact string on the site,
the truck, the invoice and the listing — a mismatch is what gets a profile renamed
or suspended, not the name itself.

Set it up as a service-area business: hide the street address, list Longmont plus
the surrounding towns as the service area. Verification needs a phone number and a
website carrying the same name and number, so the profile cannot be verified until
those exist — it comes after the domain and the business line, as §5 has it.

## 4. How to re-run the checks

The register blocks automated clients: `tmsearch.uspto.gov` returns HTTP 405 from
its S3 front on every API route, `uspto.report` and `trademarks.justia.com/search`
return 403, `tmdn.org` WAF-rejects POST. The workable route is a headless browser.

```bash
python3 -m venv /tmp/pwenv            # this machine has no pip
/tmp/pwenv/bin/pip install playwright
/tmp/pwenv/bin/python -m playwright install firefox
```

Driving the site, and the two things that cost the most time to discover:

- The search box is `#searchbar`; Enter submits. Result rows are
  `[class*=card]` containing "Serial" and "Wordmark".
- **There is no next-page control and infinite scroll does nothing.** The list
  caps at 50 per page behind a page-size dropdown whose options are in the DOM but
  hidden. Click the trigger (`button:has-text('per page')`), then click the
  element whose text is exactly `100 per page` **and whose `offsetParent` is not
  null** — matching on text alone picks a hidden copy and times out.

Colorado entity data needs no browser:

```bash
curl -sG "https://data.colorado.gov/resource/4ykn-tg5h.json" \
  --data-urlencode "\$where=upper(entityname) like '%COTTONWOOD%'" \
  --data-urlencode '$limit=400'
```

Trade names and state trademarks are published separately, and the entity
dataset above contains neither:

```bash
# Colorado trade names
curl -sG "https://data.colorado.gov/resource/u7sb-g482.json" \
  --data-urlencode "\$where=upper(tradenamedescription) like '%WAXWING%'"

# Colorado state trademark register
curl -sG "https://data.colorado.gov/resource/d3m2-b6we.json" \
  --data-urlencode "\$where=upper(description) like '%WAXWING%'"
```

Add `.com` status with:

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
  "https://rdap.verisign.com/com/v1/domain/cottonwoodandstone.com"   # 404 = free
```

### Site mechanic worth remembering

`site.js` applies `?service=` only if the value exists as an `<option>` in
`contact.html`, and the quote sheet reads `<body data-service>`. A new service
page without a matching option fails silently — the form just arrives unselected.

### Google Business Profile

The address is not the blocker: Google supports service-area businesses, where a
real address is required behind the scenes but hidden publicly and service areas
shown instead. A home address is the normal setup for a home-based contractor; PO
box, UPS Store and virtual office are prohibited. The actual blocker is
verification — video of vehicle, tools and workspace plus a business document —
for a business that is not registered and has no job history. A suspended Profile
stuck to a home address is worse than no Profile, so the Profile follows
registration and insurance.

Worth accumulating meanwhile, because it is the same evidence verification asks
for: before/after photo pairs per job, a dedicated business phone number, and
job dates with city-level locations.
